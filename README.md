# TaskFlow API

TaskFlow API to demonstracyjny projekt przygotowywany w ramach laboratoriów z przedmiotu Programowanie zaawansowane. Aplikacja będzie umożliwiała użytkownikom tworzenie i zarządzanie zadaniami. Projekt będzie rozwijany jako usługa API w ASP.NET Core w kolejnych tematach laboratoriów.

## Cel projektu

Udostępnienie API do tworzenia, przeglądania, edycji i usuwania zadań użytkowników.

## Technologie

- C#
- .NET
- ASP.NET Core
- Git

## Wymagania środowiskowe

- .NET SDK: 10.0.403
- Git
- IDE: Visual Studio / Rider / VS Code

## Uruchomienie

```bash
git clone https://github.com/gudutama/PZL-Trofimuk-Nazarii.git
cd PZL-Trofimuk-Nazarii
dotnet run --project src/TaskFlow.Api
```

Adres aplikacji jest wyświetlany w terminalu po uruchomieniu. Przykładowy endpoint z szablonu projektu: `/weatherforecast`.
